# Harness 五表实验后的修复与验证

日期：2026-11-03。修复依据为版本 `d6e1b9b` 的实验 `run_72ebad44576946bdb76385d2`。实验和本地审计保留在 `runs/full-extraction-harness-20261103T162946Z/`，不随代码上传业务数据或轨迹。

## 结果与问题

原实验 435.25 秒完成，调用模型 27 次，其中摘要 3 次；发布 462 个节点、930 条边。按业务身份、定向边、名称、别名和来源位置核对，核心合成 Gold 全部匹配。一个发布包包含 5 类实体、4 类关系、19 个映射，不能解释为只发现了一条业务规则。

实际缺陷集中在完成判定、探查工具和呈现。原报告为 `COMPLETED_WITH_GAPS`，可选建议被写入未决；两个合法只读 SQL 被拒；240 个联合组合只有三种末项编码标签；每次探查重复附带知识正文；轨迹把历史压缩替换也显示成工具执行结果；报告和节点详情未完整适配 YAML 图。

## 已修改的行为

| 问题 | 修改 | 保留的边界 |
| --- | --- | --- |
| 建议导致任务有缺口 | 草稿区分 `unresolved`、`decisions`、`suggestions`；只有真正未完成目标影响完成状态 | 旧未决不自动消失；模型中断仍报告中断并保留已发布图 |
| 旧发布掩盖当前检查失败 | 完成判据核对当前修订的验证状态、指纹和发布版本；重新验证失败留下具体待办 | 旧图保留；恢复验证成功后允许重新确认完成，单次工具错误不直接终止整个运行 |
| 摘要增加不存在的要求 | 原始目标和 skill 放入不压缩的系统上下文；摘要只记录已有事实、成果和待办 | 提示约束不能保证模型永不误判；原生摘要仍保留供核查 |
| CTE 的 `COUNT(*)` 被拒 | SQLite 授权器仅接受当前经过 SQLGuard 校验的 CTE 派生读取；查询结束即撤销 | 物理表、列权限不放宽，不能通过伪造派生来源参数授权 |
| JOIN 附加过滤被误拒 | 存在有效跨别名等值约束时允许额外 ON 过滤 | OR / NOT 不能单独充当连接约束，不改写 LEFT JOIN 的 ON 语义；写入、多语句、越权读取仍拒绝 |
| 组合标签不可读 | 支持声明显示列，缺少名称时从可见关联对象生成标签；重名结合业务身份消歧 | 不按名称合并实体，不改变身份或原始标签，不引用范围外支持 |
| 上下文重复材料 | 新构图工具不自动附带知识正文；继续通过 `read_material` 按需读取 | 不为未读取的文档自动签发证据 |
| 轨迹与用量不完整 | 历史替换单独标为压缩；按实际派发记录 usage，含主循环、重试和摘要 | 缺失用量明确标为未知；缓存输入只计一次；查看旧记录不改写文件 |
| 报告仍显示旧协议 | 新报告展示发布包、类型、映射、程序统计、目标缺口及建议；统一 Web 与 report 的运行 ID | 模型执行、数据检查、独立 Gold 和客户数据库验收分别显示 |
| 详情难以辨认 | 搜索覆盖编码、身份及别名；详情分开显示业务身份、访问范围、属性和来源映射 | 不把 `public` 访问范围当经营主体，也不把技术支持记录当业务属性 |
| 模型文字统计不准 | 验证、发布和工作区工具返回确定性图统计，包括标签基数、实际组合、全图环检查 | 程序统计和 Agent 解释分别保留；多父不等于有环 |

## 验证结果

- Python 全量 2,657 项通过，启用实际 vendored Harness 与本地模拟 HTTP 网关；前端 248 项通过，TypeScript / Vite 构建通过。
- 从原轨迹取出两个失败 SQL，经修复后的实际构图工具执行，原句不变。CTE 统计返回 `3625,210,210,210,225,0,1`；多父查询返回 `10,2,0`。分别仅有 450 和 373 字符工具结果，没有重复文档正文。最后的零仅表示该查询没有二元环，完整无环结论来自全图拓扑检查。
- 原图副本回归保留全部 462 个节点 ID、930 条边、身份和 225 个英文别名；240 个组合的显示名称均可区分。原图、草稿、报告和轨迹未改写。
- 原生用量回放：输入 550,041 tokens（含缓存读取 403,584），输出 32,734，总计 582,775；其中摘要总计 75,185。峰值单次输入 32,117。三次摘要不被当作失败调用，也不遗漏其消耗。
- 原轨迹的 43 次真实工具调用与 16 次历史结果替换分开显示。
- 运行在返回预算结果前中断，或预算文件缺失时，仍保留实际派发次数；没有服务商记录的消耗不填成已测得的零。

本次没有启动新的外部模型全量实验。合成数据上的独立核对不能代替改名数据、客户数据库、客户 Gold 和稳定性验收；本机测试也不能代替 Windows/Linux CI。
