# 数据抽取工作台：用户故事与交付计划

版本：1.0，2026-10-20。

本文把工作台界面、运行服务与现有 `lightgraph` 引擎的职责分开，并定义可验收的交互。编号使用 WB，原有 [US-01～US-28](US.md) 继续用于引擎验收。

页面与接口约定见 [工作台统一设计](WORKBENCH_DESIGN.md)，本文定义对应的用户故事与交付条件。

**本轮交付是统一设计文档和可交互原型。** 原型使用合成数据演示流程，不连接数据库、不调用模型、不提供真实后台任务或权限系统。下文“首期工作台”是后续开发范围，不能据此认定后端已经实现。

## 1. 已有能力与待开发范围

| 范围 | 当前工程依据 | 工作台需要补什么 |
| --- | --- | --- |
| 数据接入 | `runtime/config.py` 与 `sources/` 支持 Gauss、Excel、CSV；有授权范围、格式参数和能力预检 | 来源表单、上传资产管理、连接凭证引用、表选择与服务端适配 |
| 分析目的 | `ExtractionGoal`、`context.py` 将目标送入发现和文档分析 | 必填目标编辑器、独立修订号、变更影响说明；项目简介不能代替目标 |
| Markdown 范围 | `documents/core.py` 区分用途与适用范围，校验表绑定、章节范围及文档修订 | 无范围声明时默认全局，已有绑定保留；多表绑定、无效绑定提示、上下文预览 |
| 结构发现 | `discovery/agent.py`、`discovery/tools.py` 提供有预算的工具循环 | 运行服务、状态事件、关键列与规则提案界面；不向浏览器转发样本或模型原文 |
| 只读查询 | `query/guard.py` 严格解析查询、限制对象/列/函数与连接形状；适配器执行只读事务 | 各工作台调用入口统一接入执行边界，补目录查询登记、部署权限及取消审计 |
| 元数据与业务图 | `catalog.py`、`metadata.py`、`store/` 有声明、解释、图事实、发布与支持记录 | 两种图的读取接口、分页/邻域查询、详情和筛选；不把候选伪装成确认事实 |
| 增量与层级 | 规则依赖、支持撤回、发布事务、相对层位和只读入口视图已有引擎实现 | 同项目、同隔离域的运行与版本管理，以及可比较的前后发布视图 |
| 数据保留 | 有短期内存批次、写入白名单、保留检查与失败恢复测试 | 上传服务、任务队列、浏览器、代理/APM、worker 的全流程保留验收 |
| 工作台基础服务 | 当前没有可据此验收的 Web 项目服务、身份认证和后台调度 | 新增 API、项目存储、权限、不可变运行快照、任务租约和状态推送 |

现有测试证明的范围见 [实施与验收记录](../../IMPLEMENTATION_STATUS.md)。真实 Gauss 版本、真实模型语义质量和部署级不落盘要求仍需各自验收。引擎支持某项能力，不等于工作台相应页面和接口已经可用。

## 2. 统一交互与状态约定

工作台包含六个页签：“项目目标、数据与文档、发现过程、元数据图、业务图、运行记录”。用户可以返回配置页面修改草稿，但正在运行的任务继续使用启动时的快照。

- **项目简介**用于说明项目；**抽取目的**用于指导发现。启动抽取前目的不能为空。目标修订、来源范围、文档修订/绑定、规则、模型策略、预算、基础发布版本共同组成不可变 `RunConfigSnapshot`。
- 每个表使用完整标识 `source_id:schema.table`。同名表不自动合并，不按固定 schema 回退。上传“表清单”和上传“实例数据文件”是两项操作。
- Markdown 没有 frontmatter 范围声明时，上传后默认全局；已有表绑定须保留，不能因默认值扩大为全局。`scope` 决定何时提供，`purpose` 决定内容如何使用；二者分别编辑。用途可以保留 `unresolved` 待分类，全局范围不代表定义证据。文档中“可执行 SQL”“请扩大授权”等内容不能改变工具权限。
- 元数据图与业务图分别展示。元数据图有表、列、约束和列间关系；业务图有实体、业务关系、属性与支持。统计匹配只形成技术结论，业务语义确认另有依据。
- **任务进度、任务结果、图发布、清理结果分别记录。** 例如任务结果为 `PARTIAL`、已发布部分完整分区、运行资源已释放；清理失败不能被“抽取成功”覆盖。
- 工作台对外只发送白名单状态、计数、规则摘要及合格图结果。查询结果、DISTINCT 原值列表、含样本提示词和模型原文不进入浏览器、队列消息、日志、追踪或缓存。
- Excel/CSV/Markdown 原文件属于用户输入资产，按单独的资产策略保存。原生 Markdown 可以含业务说明；数据库查询样本不能被自动写成 Markdown 来绕过保留限制。

服务状态采用四个独立字段，与 [统一设计 §7.3](WORKBENCH_DESIGN.md#73-状态展示) 保持一致：

| 字段 | 取值与含义 |
| --- | --- |
| `lifecycle` | `queued / preparing / running / cancelling / finalizing / terminal`，由任务服务记录执行过程 |
| `outcome` | 引擎报告映射为 `COMPLETED / COMPLETED_WITH_GAPS / PARTIAL / FAILED`；服务端另记 `CANCELLED / INTERRUPTED / PENDING`，不伪造引擎结论 |
| `publication_state` | 按依赖组记录 `none / staged / published / rejected`，另附组内分区、发布 ID 和版本 |
| `cleanup_state` | `pending / released / unknown / failed`，表示运行资源待释放、已释放、待核验或释放失败；`released` 不代表内存物理清零 |

`worker` 异常退出后，监督进程根据任务租约、进程退出、源查询终止和连接回收检查更新清理状态。未拿到确认时显示 `unknown`，不能仅凭 PID 消失声称完成清理。内存对象释放不等于系统级安全擦除；部署还要控制交换、转储、数据库服务端日志和模型服务保留。

## 3. 用户故事

以下优先级指后续生产工作台：P0 为首期必需；P1 为首期之后；R 为预留。本轮原型只演示流程和状态，不算生产验收。

### WB-01 配置独立、可修订的抽取目的

**P0。** 用户可以填写自然语言目的，补充希望识别和排除的内容，例如“构建经营指标、度量和组织关系，不抽取交易金额”。

- **Given** 新项目只有名称和简介，**When** 用户尝试启动抽取，**Then** 显示“请填写抽取目的”，不创建运行任务。
- **Given** 目标有修订 A，**When** 用户修改后保存，**Then** 生成修订 B，并展示变更会影响哪些发现、规则和文档分析；旧运行保留修订 A。
- **Given** 任务已使用修订 A 启动，**When** 草稿改成 B，**Then** 运行详情仍显示 A；模型调用使用 A，后续新任务才使用 B。

对应引擎：`ExtractionGoal`、上下文组装、目标依赖失效。工作台新增必填校验与版本管理。

### WB-02 在一个项目内组合数据库、Excel 和 CSV

**P0。** 用户可以添加多个来源，并按完整表标识选择分析范围。

- **Given** 项目已有数据库来源，**When** 上传 Excel 和 CSV 实例文件，**Then** 新来源与原来源同时保留，工作表/文件映射为不同来源下的表，不切换成互斥“导入模式”。
- **Given** CSV 有前导零编码，**When** 用户确认编码、分隔符、表头与空值规则，**Then** 元数据记录解析配置；数据按已确认规则处理，前导零不会因默认数值推断丢失。
- **Given** 两个 schema 或来源包含同名表，**When** 选择文档绑定或跨表探索对象，**Then** 必须明确完整标识；找不到对象时报告缺失，不自动替换为另一张表。
- **Given** 用户上传表清单，**When** 导入结束，**Then** 只产生待选择的表引用，不把清单本身当业务实例表。

来源列表默认显示已知行数及其来源，未知显示“未统计”。精确 `COUNT(*)` 单独受预算管理，不能作为添加每张表的强制步骤。

### WB-03 接入凭证与项目权限分开管理

**P0，真实服务接入前必须完成。** 用户只看到有权使用的项目、来源、文档与图。

- **Given** 后端保存数据库连接配置，**When** 浏览器读取项目或导出配置，**Then** 只返回凭证引用和脱敏连接信息，不返回密码、DSN 密钥或模型 API key。
- **Given** 用户无权读取某来源，**When** 直接构造元数据、运行、图读取或文档绑定 API 请求，**Then** 服务端拒绝；隐藏前端按钮不作为权限措施。
- **Given** 分析目的缩小到部分列，**When** Agent 运行，**Then** 可见对象取部署授权与目标范围的交集；目的不能扩大数据库授权，也不能代替行级权限。

当前引擎的隔离域和来源范围不能替代工作台用户认证、项目成员权限或数据库行权限。现有 Gauss 适配器只接入基础表；授权视图属于后续安全适配，不能作为本期已支持的接入方式。实际账号与目标数据库支持的行权限须单独验收。本轮原型不提供真实登录或权限认证。

### WB-04 上传 Markdown 并设置范围与用途

**P0。** 未声明范围的文档上传后显示“全局”默认值，也可以改为一张或多张表。文档已有范围声明时，界面沿用该声明。

- **Given** 新上传 Markdown 没有 frontmatter 范围声明，**When** 保存文档，**Then** 默认 `global`，所有相关分析阶段都可按用途使用它，不要求命中表名关键词。
- **Given** Markdown 已在 frontmatter 中绑定表 A，**When** 上传并打开范围设置，**Then** 保留表 A 的绑定，不自动扩大到全局；无效绑定按具体错误处理。
- **Given** 文档绑定表 A、B，**When** 分析 A 或 A 与 B 的关系，**Then** 上下文包含适用章节；只分析 C 时不注入该文档。
- **Given** 文档用途为分析经验、范围为表 A，**When** 查看配置，**Then** 两项单独展示；分析经验不能自动成为确认列身份或实体等价的证据。
- **Given** 文档用途尚未判定，**When** 上传并保存，**Then** 保留 `unresolved` 待分类；即使范围为全局，也只能按探索提示使用，不能自动作为确认定义的证据。
- **Given** 被绑定的表已移除或文档范围过时，**When** 启动运行，**Then** 显示具体失效绑定，阻止以无效范围启动；不静默退回全局。

章节可以继承或缩小文档范围，不能无提示扩大。修改用途、范围或内容均形成新修订。

### WB-05 查看本次分析将使用的上下文

**P0。** 用户可以按表或跨表任务查看目标版本、适用文档和元数据解释。

- **Given** 目标、全局说明和表 A 专用说明已保存，**When** 预览 A 的发现上下文，**Then** 展示各自版本、适用范围和用途，不显示任何运行采样值。
- **Given** Agent 从 A 继续探索到 B，**When** B 有此前未读取的专用说明，**Then** 先补充 B 的上下文并重新评估提案，再做关联确认；规则依赖记录对应文档修订。
- **Given** 适用文档超过上下文预算，**When** 开始相关任务，**Then** 报告未读取的范围并延期或按可追踪章节拆分，不悄悄截断后宣称完整阅读。

预览展示文档引用和必要原文片段，这些来自用户知识资产；它不包含检索返回样本或完整模型请求。

### WB-06 检查元数据声明与语义解释

**P0。** 用户可以分别查看数据库/文件声明、程序观测结论、模型解释和待澄清冲突。

- **Given** 列注释与实际值形态可能不一致，**When** 预处理产生冲突，**Then** 原声明保留，另列候选解释、依据类型和状态；候选不能覆盖原始 YAML。
- **Given** 用户修订解释，**When** 保存，**Then** 形成解释修订及审计记录，并标出受影响的规则；不会修改源数据库列名或注释。
- **Given** 外键或检查约束无法从当前适配器取得，**When** 查看元数据，**Then** 显示“未知/未取得”，不能显示为“已检查、没有约束”。

YAML 下载包含声明与解释版本。原始声明 YAML 只读，界面可按表结构、约束、外键分区查看。用户只能编辑补充说明或覆盖建议，经过结构校验后作为独立解释修订提交，不能改写原始声明。

### WB-07 浏览表、列及跨表列关系

**P0。** 元数据图可以展开表下的列，并查看列间关系的来源和状态。

- **Given** A 表 a 列与 B 表 c 列存在候选映射，**When** 展开两张表，**Then** 可见表到列边及 a 到 c 的边；关系详情包含完整端点、关系类型和候选/已核验/拒绝状态。
- **Given** 声明外键、统计重合和语义解释同时存在，**When** 筛选关系，**Then** 三者分别标识；统计核验成功不自动显示为业务含义确认。
- **Given** 图较大，**When** 查看某列邻域，**Then** 服务端按范围、数量和分页返回；页面显示“当前加载/总计或未知”，不让局部图看起来像完整图。

颜色之外还须有文字/线型区分，图节点有可搜索列表替代入口。点击列可返回 YAML 对应字段。

### WB-08 查看 Agent 自主发现过程与关键列结果

**P0。** 用户能知道 Agent 当前验证什么、使用什么工具、哪些范围尚未覆盖。

- **Given** 目标只关注指标与组织结构，**When** Agent 读取元数据并提出候选列，**Then** 列按编码、名称、属性、层级、引用和排除项展示；排除项给出无原值原因。
- **Given** 发现过程使用有界样本，**When** 查看活动记录，**Then** 只显示工具类型、对象范围、耗时、计数、预算与状态；不展示样本、参数值、SQL 原文或模型思维过程。
- **Given** 模型提出关系规则，**When** 程序验证未通过或预算不足，**Then** 分别标为拒绝、未决或延期，并说明缺少哪项检查；不发布为确认关系。
- **Given** 一个表失败、另一个成功，**When** 后续继续运行，**Then** 失败表仍需重试，成功表可复用已满足依赖的结果。

活动记录不是聊天窗口。Agent 提案须编译为受限规则并接受结构与发布验证。

### WB-09 所有来源查询经过只读执行边界

**P0，真实数据接入前必须完成。** 用户和管理员可以确认每种工具都不能绕开 SQL 守卫。

- **Given** Agent 或规则工具提交 SQL，**When** SQL 含写入 CTE、`SELECT INTO`、多语句、DDL、事务控制、锁、危险函数、未授权对象或未知语法，**Then** 执行前拒绝，数据库未收到该语句。
- **Given** 查询通过严格 AST 校验，**When** 执行，**Then** 仍受只读账号/事务、表列授权、参数绑定、超时、返回行数/字节、内存和累计查询预算约束。
- **Given** 工作台新增元数据刷新或预检入口，**When** 进行目录读取，**Then** 只允许登记过的固定目录查询，绑定参数并约束来源范围；不能借“元数据查询”调用任意驱动 SQL。
- **Given** 查询带 `LIMIT`，**When** 估算资源成本，**Then** 不将 LIMIT 当作限制扫描成本的证明；预算耗尽或超时可取消。
- **Given** 被拒绝的 SQL 本身含 canary，**When** 触发解析 warning、解析失败或驱动异常，**Then** parser/driver 日志、异常对象对外载荷、HTTP 和 SSE 均不得泄漏 SQL 全文、参数值或 canary；不能只检查最终错误码。

SQL 前缀判断、黑名单字符串替换和只隐藏按钮均不满足验收。用户输入、文档内容与模型输出不能修改守卫策略。

**历史阻断项已在引擎修复：** 原型评审曾复现 `EXPLAIN` 被拒绝前，SQLGlot 已在 warning 中记录 SQL 全文。后续 AgentScope 迁移已在警告产生前阻断，并加入拒绝路径日志测试。正式 worker 的 HTTP/SSE 和驱动日志尚需按上述用户故事验收。详见 [统一设计 §4.2](WORKBENCH_DESIGN.md#42-sql-守卫)。

### WB-10 提供足够的结构发现工具

**P0。** Agent 可以提出可核验的列组、层级和跨表关系，不依赖按数据集硬编码列名。

| 工具类别 | 输入与输出要求 | 核验边界 |
| --- | --- | --- |
| 元数据读取 | 授权表、列、类型、注释、约束及能力信息 | 不借目录读取扩大授权 |
| 单列/组合画像 | 空值率、唯一率、值形态计数、联合 DISTINCT 规模 | 统计不足显式未知；不保留原值列表 |
| DISTINCT 联合投影 | 指定关键列、谓词、行数与内存上限 | 截断不得作为完整删除对账依据 |
| 函数依赖检查 | 复合键到名称/属性的违例计数 | 一对一关联不等于语义等价 |
| 有界分层样本 | 目标列、分层条件、小样本上限 | 仅内存提供给获准模型；不进入事件和浏览器 |
| 层级核验 | 槽位、缺层、填充、环、多父及体系条件 | 相同实体在不同深度不自动生成不同身份 |
| 同源跨表核验 | 明确连接键、授权表列、受控等值连接 | 禁止无界笛卡尔积；统计引用与业务语义分层 |
| 跨来源比较 | 两端分别受守卫查询，在有界内存比较键元组 | 不承诺分布式同时快照；预算/一致性不足则未决 |
| 文档检索与反例检查 | 精确文档范围、修订、用途及待验证假设 | 提示只作候选；定义证据需满足独立校验 |

- **Given** 仅提供元数据、目的和允许的说明，**When** Agent 发起上述工具调用，**Then** 记录工具与核验覆盖，数据类工具生成的 SQL 均进入 WB-09 的边界。
- **Given** 跨来源比较只读取了截断片段，**When** 输出候选引用，**Then** 标明覆盖不完整，不确认全量唯一性、不撤回旧事实。
- **Given** 新数据不符合既有模式，**When** 增量运行，**Then** 发起针对反例的复核或延期；不以“已有规则”跳过冲突。

工具表描述首期目标集合。已有算子、规则验证和 Agent 可直接调用的工具可能分布在不同模块；接入时逐项登记，不能仅根据模块存在就显示“Agent 已可使用”。

### WB-11 启动不可变、可取消的后台运行

**P0。** 运行不依赖用户停留在页面上。

- **Given** 配置与基础发布版本已确认，**When** 点击开始，**Then** 服务端原子创建快照和任务 ID，重复提交使用幂等键，不能启动两次同一请求。
- **Given** 任务正在运行，**When** 切换项目、刷新或关闭页面，**Then** 任务继续由后台管理；重新进入能按任务 ID 恢复状态，不重新触发抽取。
- **Given** 用户取消，**When** 服务端接受取消请求，**Then** 显示“正在取消”，停止新工具调用、取消活动查询并清理；确认完成后再显示取消结果。
- **Given** 发布已提交但随后的清理失败，**When** 查看结果，**Then** 已发布版本仍可追踪，清理失败单独告警，不将发布改写成未发生。

每个事件包含项目、运行、序号、时间和白名单载荷。重新订阅按序号补齐、去重，旧任务事件不能写入新项目的页面状态。

### WB-12 运行结束后确认样本与临时资源清理

**P0。** 样本从读取开始就不得落盘，在不再需要时释放，运行终止时做最后确认。

- **Given** 任务成功、失败、取消或重试，**When** 结束当前执行尝试，**Then** 关闭源游标/连接和临时内存数据库，销毁样本引用、模型请求缓存与工具上下文；报告清理结果。
- **Given** worker 崩溃或租约过期，**When** 监督进程接管，**Then** 确认进程退出并检查源查询终止；清理无法确认时保持 `unknown/failed`，阻止自动标为完成。
- **Given** 排除列含 canary 值，**When** 执行成功、异常、取消、重试、崩溃和流式路径，**Then** 工作台存储、浏览器网络载荷、队列、日志、临时文件及部署追踪均找不到该原值。
- **Given** 尚未执行、已被守卫拒绝的 SQL 含 canary，**When** 解析器或驱动生成诊断，**Then** 同样检查 parser/driver 日志、异常、HTTP 和 SSE 无泄漏；运行结束时删除样本不能补救此前已输出的原值。
- **Given** 用户主动上传 Markdown/Excel/CSV，**When** 查询样本完成清理，**Then** 不误删依资产策略允许保存的原文件和已经校验发布的图结果。

恢复任务重新按需查询，不从源数据缓存恢复。允许保存的计数和控制状态采用白名单；把样本哈希、自由 evidence、模型全文或 DISTINCT 返回体保存下来同样不合格。

WB-09 所列 parser warning 泄漏仍未修复，因此本项尚不能作为正式 worker 接入的已通过条件。

### WB-13 浏览业务图与来源支持

**P0。** 用户可以检查节点和边为什么存在，以及哪些来源仍支持它们。

- **Given** 图中有一个实体由 A、B 两张表共同支持，**When** 点击实体，**Then** 分别显示身份、属性、别名、业务关系及各自来源/规则/文档/发布支持，不能只给一个含糊“来源”字段。
- **Given** 支持 A 被撤回、B 仍有效，**When** 刷新当前发布视图，**Then** 实体保留，仅撤回 A 独有的属性或关系；历史发布仍可查看。
- **Given** 同一对象出现在相对 L2、L3 位置，**When** 查看不同入口的层级视图，**Then** 可显示不同深度，实体 ID 和已确认父子事实不因入口变化而改写。
- **Given** 某业务边只有文本主张或未决语义，**When** 打开确认业务图，**Then** 默认不混入确认事实；可单独查看候选/主张和对应状态。

合格图结果可以含实体名称、编码等业务属性；“浏览器不见查询样本”不禁止浏览经校验的目标图结果。

### WB-14 在已有非空图上继续抽取

**P0。** 首期支持同项目、同隔离域的已有发布，运行前图谱可以不为空。

- **Given** 当前发布 P 已有实体和支持，**When** 创建增量任务，**Then** 运行记录基础发布 P，界面可继续查看 P；新结果校验通过后才发布。
- **Given** 新来源包含已确认的同一实体，**When** 增量执行，**Then** 复用身份并增加支持；不能单凭名称相同合并，也不能因来源不同一律复制节点。
- **Given** 本次分区读取被截断或中断，**When** 对账，**Then** 不把未读到的旧事实当作已删除；显示未完整对账范围。
- **Given** 另一运行已先更新基础发布，**When** 本任务尝试提交，**Then** 依据服务端 generation/CAS 检查拒绝冲突提交或重验，不静默覆盖。

目的、文档、schema、规则或身份依据变化时按依赖重算；“增量”不承诺零扫描。界面明确本次是复用、重验、重投影还是未覆盖。

### WB-15 安全保存草稿与处理并发修改

**P0。** 自动保存不会覆盖其他用户或标签页的新修改。

- **Given** 浏览器读取项目修订 R，**When** 自动保存，**Then** 请求携带 `If-Match: R` 或等价修订条件；服务端保存成功后返回新修订。
- **Given** 另一标签页已保存 R+1，**When** 旧页面提交 R，**Then** 返回冲突，界面保留本地草稿并显示差异，可重新加载或明确合并，不能静默覆盖。
- **Given** 草稿尚未保存，**When** 点击开始或切换项目，**Then** 先解决保存状态；启动任务必须指定已保存修订。项目切换不会把旧项目保存响应写到新项目。
- **Given** 目标/绑定修改会影响已发布图，**When** 保存草稿，**Then** 先记录配置变更，不立即删除发布事实；实际失效和重算属于显式新运行。

保存状态至少区分“未保存、保存中、已保存、冲突、失败”。网络错误不显示“已自动保存”。

### WB-16 查看运行结果、未覆盖范围与清理状态

**P0。** 用户能区别任务结束与业务验收通过。

- **Given** 运行结束，**When** 打开报告，**Then** 同时显示任务结果、发布版本/分区、清理状态、预算消耗、接受/拒绝/未决规则、已覆盖与未覆盖表范围。
- **Given** 后端退出码为 0 但有延期任务，**When** 展示状态，**Then** 结果为部分完成，列出继续运行所需条件；不显示“全量抽取成功”。
- **Given** 用户导出报告或图，**When** 生成下载，**Then** 只包含对应输出契约允许的元数据、图结果、规则与无原值统计；不附带样本、提示词、模型原文或凭证。
- **Given** 任务使用模拟数据或固定模型响应，**When** 查看验证标签，**Then** 标明“合成/模拟验证”，不等同于真实 Gauss 或真实模型验收。

### WB-17 保留跨项目继承入口

**R，首期不开发。** “继承已有项目”仅作后续用户故事，不能冒充当前的同项目增量。

- **Given** 首期工作台，**When** 用户查看项目操作，**Then** 继承入口隐藏或标明“规划中”，不能点击后假装复制了图和权限。
- **Given** 后续实施继承，**When** 选择来源项目，**Then** 必须显式选择配置、文档或已发布图，并逐项检查权限、隔离域、身份冲突、来源支持和可撤回性。
- **Given** 复制项目配置，**When** 目标项目创建，**Then** 不自动复制密钥、任务、源数据缓存或已确认权限；是否复用结果必须独立确认。

### WB-18 提供可验证的交互原型

**本轮交付。** 原型用于核对信息结构和操作，不承诺后台能力。

- **Given** 打开原型，**When** 查看页面，**Then** 持续可见“交互原型/合成数据”说明；真实连接、上传、保存、启动和取消不呈现伪造的真实服务成功。
- **Given** 用户编辑目标、切换文档全局/表绑定、选择图节点或演示运行，**When** 操作完成，**Then** 能观察到对应状态和详情变化；示例由页面内合成模型驱动。
- **Given** 用户刷新本原型，**When** 页面重新加载，**Then** 恢复初始合成示例，草稿与模拟任务重置；界面明确这一行为，不承诺刷新后继续任务或服务端持久化。
- **Given** 键盘操作和窄屏，**When** 切换页签、选择图节点、打开详情或关闭弹层，**Then** 操作入口可达，内容可读；图节点可用键盘选择并查看文本详情。本轮原型没有全图搜索，搜索能力仍按 WB-07 留待正式工作台开发。

## 5. 验收场景表

固定输入使用合成的数据库替身、Excel、CSV 和 Markdown；真实接入另记录环境。原型只能验收界面行为，不能代替引擎或部署验收。

表中“原型；API/worker”等表示场景横跨多个验收层，不表示本轮已验证完整场景。本轮原型只操作其中的界面子集，例如目的输入、混合来源选择、文档范围切换、图节点详情和模拟运行状态。运行目标冻结、同名表真实接入、后台恢复、权限、存储及查询行为仍待 API/worker 或适配器验收；具体已检查的原型操作以 [原型说明](../../src/lightgraph/workbench_prototype/README.md) 为准。

| 场景 | 操作与故障 | 应观察到的结果 | 验收层 |
| --- | --- | --- | --- |
| WBF-01 目标缺失与修改 | 只填简介启动；运行中修改目标 | 缺目标不能启动；旧运行目标版本不变 | 原型；API/worker |
| WBF-02 混合来源同名表 | DB、Excel、CSV 都含 `metric` | 来源共存，绑定以完整标识区分 | 原型；适配器/API |
| WBF-03 文档默认及绑定 | 无声明文档默认全局；已有绑定保留；改绑 A/B，分析 C | 不扩大已有范围；A/B 生效，C 不注入；用途不随范围改变 | 原型；上下文 |
| WBF-04 跨表新文档 | A 提案引用 B，B 有专用约束 | Agent 先读 B 文档，重评提案，记录修订依赖 | Agent/worker |
| WBF-05 文档失效与超限 | 移除被绑定表；扩大文档体积 | 阻止无效绑定启动；超限报告缺口，不静默截断 | API/上下文 |
| WBF-06 元数据图 | 展开两表和列关系，筛选候选 | 表列层次和跨表列端点可见；声明/技术/语义状态分开 | 原型；图 API |
| WBF-07 危险查询拒绝集 | 写入 CTE、多语句、INTO、函数、锁、越权列、无界 JOIN；含 canary 的 `EXPLAIN` 等拒绝语句 | 执行前拒绝；源库无写入；parser/driver 日志、异常、HTTP/SSE 无 SQL 原文、参数与 canary。当前 parser warning 缺口未修，正式 worker 接入前必须通过 | 守卫/实际 Gauss；日志与传输 |
| WBF-08 样本边界 | 样本中植入排除列 canary，走六类路径；另在被拒绝 SQL 中植入 canary | 事件/浏览器/parser 与 driver 日志/异常/HTTP/SSE/队列/磁盘均无 canary；清理状态有依据，不能用结束后删除掩盖先前泄漏 | worker/部署；拒绝路径当前有已知缺口 |
| WBF-09 页面离开与取消 | 开始后切换项目、刷新、取消 | 正式服务中只有一个任务，按服务端状态恢复；取消确认前显示处理中。真实后台恢复 API/worker 待开发，本轮原型刷新即重置，不承诺继续任务 | API/worker；原型只验页面内演示 |
| WBF-10 保存竞争 | 两标签页基于同一修订保存 | 后提交返回冲突，本地草稿保留 | API/前端 |
| WBF-11 非空图增量 | A/B 共享实体，撤回 A 的独有别名 | 实体与 B 支持保留，A 独有内容撤回，可查看旧发布 | 引擎/图 API |
| WBF-12 不完整对账 | 中途预算耗尽、结果截断、查询失败 | 保留旧支持，标未完整分区，不做缺失删除 | 引擎/worker |
| WBF-13 发布与清理解耦 | 发布成功后注入清理故障 | 已发布版本仍在；清理故障单独显示与处理 | worker/存储 |

## 6. 完成判断

本轮完成要求是设计和原型可对照评审，且原型说明真实未接通的部分。生产工作台完成要求是 P0 故事逐项有接口、代码和验收记录；引擎测试数量、页面可打开、图节点数量或任务退出码均不能单独代替这些证据。
