# 按只读快照管理连接，限制故障后的重复调用

日期：2026-11-05。接续 [数据库重连与探查方法](DISCOVERY_RECOVERY_AND_FULL_GRAPH_20261105.md)。本轮依据用户转述的真实运行及本地故障注入，不访问客户数据。

## 已确认的问题与尚未确认的原因

当前故障注入可复现连续 62 次实例校验：每次都尝试打开失败来源，返回未通过，却没有触发停止条件。原实现的来源隔离只在单次校验内有效；下一次调用又清空失败状态。`retryable=false` 和 skill 中的停止要求不能阻止模型再次调用。

原数据库连接从适配器创建一直保留到运行结束，跨越模型思考、压缩和 Excel 分析。明确断线可以触发重建；驱动仍认为连接打开、BEGIN 与回滚均失败时，恢复判断不完整。没有 SQLSTATE 不能单独证明防火墙回收，客户现场的网络、服务端超时或驱动原因仍需日志确认。

## 连接属于一次完整快照

Gauss 和 MySQL 在元数据预检后释放连接。后续每个最外层只读快照获取新连接，重新检查只读控制、能力、产品版本和授权目录。多条投影、同源查找和嵌套查询共用该快照；快照结束后释放连接。缓存的授权元数据和内存中的连接配置仍保留，模型思考期间不保留空闲数据库连接。

重建使用原来的查询次数、返回量和墙钟预算，不重新发放额度。连接及资格检查会增加开销，这部分计入预算和轨迹；不承诺短连接消除活跃查询期间的网络故障。用户主动关闭或取消不会触发恢复。

首次 BEGIN 尚未返回数据时，若错误类别明确属于连接，或者类别未知且回滚也失败，可以丢弃不能安全使用的会话，再建立一次经过资格检查的连接。权限、认证、目录或能力错误不按网络故障反复重试。恢复失败保存稳定的错误码与安全诊断，后续不再重新连接。

已经读取部分数据的快照失败后，本次校验仍失败。不得接续旧查询、拼接新旧结果，或把多来源独立快照描述为同一个数据库时点。

## 来源级停止与运行收尾

工具维护本次运行的来源状态，保存到 `source-circuits.json`，并通过工具结果、工作区和运行报告返回。只保存来源标识、错误码、安全驱动诊断和计数，不保存原始异常、SQL 或事实行。

- 适配器恢复失败或目录资格失效，立即停止该来源的事实操作。
- 其他连接或事务开关故障，最多允许三次连续失败的独立操作；一次调用中的 94 个映射只计一次失败。普通查询超时、SQL 改写错误和名称冲突不据此停止整个来源。
- 未锁定前，真实数据操作成功会清零连续失败计数；读元数据、改 SQL、换草稿编号、压缩上下文均不会清零。
- 首次混合校验仍保留健康来源候选。来源锁定后，含它的后续实例校验在执行前返回 `source_circuit_open`，不再重算健康来源，也不覆盖已有验证记录。结构检查、保存草稿和健康来源独立任务仍可继续。部分候选不能直接发布成完整混合图。
- 已锁定来源又收到三次事实请求时，工具写入 `source_retry_limit_exhausted`。Harness 最多再允许两次模型分发用于收尾，重试和压缩也计入；之后不再调用模型。先前成功的验证产物仍可按原有发布契约发布，不重新查询数据。

来源锁定由程序执行，Agent 不能通过更换草稿编号或重新描述目标解除。新运行重新检查来源，不永久沿用旧失败判断。操作人员恢复数据库后可以重新运行；历史草稿和验证产物不删除。

## 验证范围

回归需覆盖：半开连接、BEGIN 与回滚失败、恢复失败稳定错误、快照结束释放、同快照多查询、活动快照不重放、权限与目录变化拒绝、预算不复位、取消不复活；以及重复 62 次请求被有限调用拦住、健康来源继续、跨来源引用检查、草稿保留、真实 Harness 收尾次数。

本地驱动替身与脚本模型验证上述控制行为，不代表客户 Gauss 的连接生命周期、两亿行性能或 Agent 的语义建模质量已验收。修改后的连接逻辑从新启动的进程生效，正在运行的旧进程不会自动换代码。

实施结果：完整后端回归 2,993 项通过；最后对计数去重的修改完成相关 42 项回归（含实际 Harness 与原生压缩）；前端 331 项和构建通过。测试记录见 `runs/snapshot-lifecycle-20261105/`，实施范围与限制见项目根目录 `IMPLEMENTATION_STATUS.md`。
