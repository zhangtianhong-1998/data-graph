## 调整

- Windows job 总时限由 35 分钟改为 60 分钟，覆盖依赖安装、前置检查、完整测试及清理。
- Windows 完整测试步骤单独限制为 55 分钟，使卡住的测试在 job 到限前结束，并留出清理时间。其他平台维持 20 分钟 job 时限，完整测试步骤上限为 17 分钟。
- 平台和 Python 版本矩阵、完整测试命令、冻结实验前置检查及 SQLite 持久性设置保持不变。

以当前进度粗略外推，Windows 3.11 完整测试可能需要约 37 分钟，另有约 3 分钟安装和前置检查；这只是预算估计，不是已测得的完成时间。60 分钟为 runner 波动留出余量。此次采用配置修复，不增加测试分片机制。

## 验证边界

本地检查 workflow 的 YAML、四个平台版本组合、步骤时限与完整测试命令，并确认 pytest 可以正常收集全部测试。本地验证不能代替 Windows 完整执行；下一次提交的 Actions 才能确认该平台是否在新时限内通过。
