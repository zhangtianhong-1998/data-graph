# 单文件层级数据：问题核查与实验口径

## 真实数据反馈的边界

本地没有用户的真实工作簿和完整轨迹。2,973 节点、5,504 条边、22 次调用等数字属于用户提供的分析，不能写成本机复验结果。发布成功和会话记录完整是两个独立检查；会话校验失败不应删除已发布图，也不能一律忽略真实的持久化错误。

代码核查确认：Harness 会话目录使用普通 Python glob 扫描；在 Windows 长路径未生效的环境，可能漏掉 Node 已写入的文件。修复在 Python 文件访问边界统一使用扩展长度路径，包括会话扫描、后续读取、请求/用量台账、预算和运行配置；SDK 与报告继续使用普通路径。日志真正缺失仍报错，不能靠放宽判据伪报成功。新增中文长路径的实际内核回环测试，Windows 真实平台仍以对应 CI 为准。

图谱搜索只返回命中节点及命中集内部的边，不能据此判断节点孤立。邻域查询原先还把 q/kind 过滤应用到邻居；修复后先保留权限过滤，再独立扩展焦点邻域，分页保留中心与连接路径，并提示展示范围。搜索定位补一跳，双击仍查看两跳。

## 身份、层位与路径

旧图已经保留来源列和映射编号，不能说层位信息全部不存在。但是，各映射独立 DISTINCT 后没有共同的行上下文，边集合无法证明某条完整来源路径出现过。

通用映射新增两个可选字段：

- `constant_properties`：Agent 对该映射声明的固定位置等属性，与来源列属性不能同名，不参与身份。
- `context_columns`：经授权投影的行上下文列。同一来源、相同列集合及列值生成共同的 `row_context.id`，在每份支持中保留值。

因此同一业务编码仍是一个实体，同一端点对仍是一条边，但不同层位、不同路径分别保留支持。省略同码自环不删除实体的行证据。相同内容行按内容去重；上下文 ID 不是物理行号或重复次数。所有新增列同样遵守授权、排除列、范围过滤和资源上限。

构图 skill 提示 Agent 在目标需要时保留位置和路径，并验证连续重复值的含义，不预设任何业务列名。统计新增无出边节点、无任何边节点、同时有入边和出边的节点及行上下文数量。它们是观测统计，不自动证明“占位数据”；一个没有观测到下级的合法对象也可能只有归属边。

## 新模拟数据

用户选择保留 16 列；超过五节点的路径拆成连续重叠片段，短路径用真实叶子向下填充。生成说明明确有些行是片段，不能称为完整根叶路径。优先遵守明确给出的编码和树，不强行让编码数值大小符合层级，也不为达到预估规模重复造行。

给定 PL 和 OCF 分别是树；每节点分别作根不会凭空产生多父。跨层位复用不等于多父；同名、不同完整编码不自动跨领域合并。多父行为另用有明确多父边的程序测试覆盖，不擅改用户样例。

生成器独立真值：10 个责任中心、3,870 个唯一数据行、1,190 个指标编码、1,170 条父子边、20 个根，最大深度 8（PL 8、OCF 7），1,170 个指标跨层位出现。完整根叶路径枚举 4,180 条，窗口候选 4,750 条，完全重复的导出窗口去重 880 条。来源位置事实 5,460 条。数字由生成器计算，随后独立读回 Excel 核对。

## 实验隔离与验收

新建空白项目，只提供一个 Excel 和用户级抽取目标。不导入固定规则、旧图、候选、生成器、树定义或 Gold。模型沿用已配置接口，最多 1,000 次调用，累计 tokens 不限，单次输入/输出及超时分别生效。目标要求发现指标与责任中心、层级/归属、名称/别名、身份复用、位置及来源行上下文；列映射和解释由 Agent 自主提出。

验收分别核对节点身份、父子边集合、名称与英文别名、中心归属、物理位置和可重建的导出行上下文；检查漏项、多余、自环、悬空边、循环和错误合并。运行状态、工程测试和图数量都不能代替这些核对。保存完整轨迹和原始产物，不覆盖上一轮实验。

## 本机验证

后端全量 2,678 项通过（93.28 秒，启用实际 Harness 回环测试）；前端 251 项通过，生产构建通过。Excel 已由独立 OOXML 读取逐格核验并渲染检查，文件哈希与验证记录保留在本地实验目录。以上不是实际模型的抽取质量结果；模型实验另行留存运行报告与独立评分。
