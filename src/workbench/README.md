# Vue 3 数据图谱工作台

这是通过 HTTP API 连接 Python 后端的 Vue 3 + TypeScript + Vite 工程。页面不生成演示项目或模拟抽取结果；项目、文件、配置、元数据、运行状态和图谱都来自 `/api`。

## 开发与构建

使用 Node.js 22.12+（22.x）、24.x 或 26+，在此目录运行：

```sh
npm ci
npm run dev
```

开发服务监听 `127.0.0.1:5173`，将 `/api` 转发到 `127.0.0.1:8000`。先按主工程说明启动后端。

```sh
npm test
npm run build
```

生产文件生成到 `src/workbench/dist`，由 Python 后端提供同源访问。没有 CDN、浏览器数据库、localStorage、IndexedDB 或 Service Worker。

## 使用流程

1. 新建项目；后端自动创建 `workspace/<project_id>/`。
2. 上传 XLSX、CSV、Markdown 或 YAML。数据和 Markdown 自动登记到配置，YAML 需要点击导入。也可在「数据与文档」或「Agent 与配置」中添加 MySQL / Gauss 数据库来源。
3. 设置抽取目标，配置模型地址、模型名称和服务端 API key 环境变量名。
4. 读取元数据；Markdown 可保持默认全局，也可绑定一张或多张表。
5. 开始抽取；页面每秒查询真实任务状态。终态到达后重新读取图谱和报告。

数据库表单支持来源编号、数据库类型、`dsn_env`、允许查询的表和能力验证文件。MySQL 表名使用 `database.table`，Gauss 使用 `schema.table`，一行一张表，不能用通配符。两种数据库可以与上传文件共存。连接信息仅通过服务端环境变量提供，前端不能提交明文密钥或数据库连接串。

能力验证文件只能选择此项目已经上传的 YAML。部署留存确认需要用户明确勾选，不会因保存数据库配置而自动开启；未确认时可先保存配置、读取元数据，但不能进行真实实例数据抽取。编辑数据库来源保留已有 `allowed_columns` 和其他高级字段；来源编号保持不变，避免破坏已有绑定。完整 JSON 编辑器仍用于精细配置。

项目配置在服务端以 YAML 保存，后端负责最终的权限与配置校验。

## 范围

- 展示已有项目图谱并允许在原项目启动后续抽取，不清空既有图来制造运行效果。
- 图支持搜索、类型筛选、点击详情、缩放和平移；每次绘制最多 240 个匹配节点，超过时明确提示先筛选，完整结果仍在后端。
- 模型 SSE 开关控制后端模型接口；此版运行状态采用 HTTP 轮询，不展示模型原文或样本数据。
- 文档原文仅以文本预览，不渲染 HTML；业务查询样本不提供预览入口。
- 配置修改保留未编辑字段。完整 JSON 编辑器需单独保存，运行不会悄悄采用未保存的 JSON。
- 运行报告与错误不等于业务验收成功，`partial`、失败、取消和临时数据清理未确认都会明确展示。
