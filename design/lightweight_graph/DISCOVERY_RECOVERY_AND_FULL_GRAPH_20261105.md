# 自主探查、数据库重连与完整画布

日期：2026-11-05。延续 [混合来源故障修复](MIXED_SOURCE_FAILURES_20261105.md)。本轮依据用户转述和本地代码复现，没有访问客户数据库。

后续变更：[只读快照连接与重复失败控制](SNAPSHOT_CONNECTION_LIFECYCLE_20261105.md) 替换下述“连接跟随整次运行”的生命周期，并补上跨调用的失败计数与停止控制。本页保留上一阶段的设计依据和验收记录。

## 现有修复覆盖到哪里

前一轮修复事务清理、错误分类、独立来源候选、名称覆盖和修订损失提示。这些能减少执行故障造成的退化，但尚未提供数据库自动重连，也不能证明 Agent 的探查策略已经适用于大表。

用户提供的分析包含合理线索，也有尚未证实的因果推断。缺少 SQLSTATE 只表示没有可用的服务端错误码；没有它不能单独认定连接死亡。BEGIN 立即失败也可能是已中止事务、客户端状态或配置问题。某次 DISTINCT 超时不能证明之后的断链由它引起。需要同时记录驱动连接状态、操作阶段、错误分类和恢复结果；实际网络或数据库根因仍需现场日志。

参考：[Psycopg 连接状态](https://www.psycopg.org/psycopg3/docs/api/connections.html)、[Psycopg 异常](https://www.psycopg.org/psycopg3/docs/api/errors.html)。数据库查询的 LIMIT 约束结果行数，不保证约束聚合、去重或排序的扫描工作，参见 [PostgreSQL SELECT](https://www.postgresql.org/docs/current/sql-select.html)。这些协议说明不能代替对客户 Gauss 版本的验证。

## Agent 的探查方法

保留 Harness 自主循环，不恢复固定表顺序、固定阶段额度或硬编码的层级规则。Skill 要让 Agent 从目标提出待验证问题，再选择操作，而不是先对所有列计算精确画像。

1. 读取目录、定义文档和少量带列名的样例，提出对象、身份范围、名称和位置候选。
2. 将已有字段映射和剩余疑问保存进草稿，先做不查询事实的结构检查。已有名称和路径需求与对象一起保留。
3. 只对当前候选选择有区分力的统计或记录匹配。工具材料明确 profile 的逐列聚合、FD 的查询数和样例的证明边界。
4. 查询超时后读取错误阶段和状态，改探查问题、必要列或有依据的范围。不得原样反复扫描，也不得把样本成功说成全量成立。
5. 分开报告结构方案、完整实例验证和发布结果。写在决策文字中的度量不是图中 Measure 对象；本阶段尚未实现的列级对象映射已在[后续修订](METADATA_OBJECTS_AND_RELATIONS_20261105.md)补充，须提供授权物理列及适用材料证据。

以上通过 skill、按需参考和错误反馈影响 Agent 决策，不宣称提示词可以保证自主发现质量。真实模型需要另做固定输入对照。

保存新草稿和读取工作区时，还会返回因来源或资源失败保留的其他草稿。它补上“换一个 draft_id 就看不到旧受阻方案”的提示缺口。提示只给修订、来源、定义数量和错误码，不自动认定全部候选都是目标要求，也不阻止独立方案发布。

## 重连边界

仅在新最外层只读快照开始前，依据明确连接错误或驱动的 closed/broken 状态尝试有界重建。原连接配置和凭据仅驻留内存；恢复必须重做只读及能力验证，比对目录、物理列及连接绑定。凭据、权限、目录变化和未知但仍开着的连接错误不能靠自动重试绕过。

重建沿用整次运行的查询和时间预算。重建失败不能让后续每次工具调用继续无限重建。用户主动关闭或取消不触发恢复。旧连接的超时取消只作用于旧连接。

正在读取的快照一旦失败，当前验证仍失败，已有独立来源结果仅为候选。新连接只能用于下一次完整验证，不能续接部分行、自动替代历史验证时点或宣称分布式一致快照。

## 运行诊断

工作进程必须留存退出状态、包内异常位置、驱动类别和安全错误字段，前端可读取和导出。仅把 stderr 改成原文文件仍可能泄漏 SQL、凭据或事实值；采用有界结构化日志，原始流持续排空，只保留允许的字段和计数。记录被截断或写入失败要明确说明，不伪装为完整日志。

## 完整圆形画布

原前端超过 1,000 节点不续载，并有 4,000 节点、16,000 边截断；原后端节点页只返回页内边，不能通过简单拼接页面获得完整关系。

新增节点与边独立批次读取，整次加载绑定同一个授权图版本。各页复核当前权限和版本，变化时不混合旧新图。前端自动续载全部批次，并提供进度、暂停/继续、失败状态；暂停或失败不表示全图已加载。

实例节点继续使用圆形 Canvas。视口只绘制可见元素，但不丢弃视口外已加载的节点和边；两跳和搜索基于完整已载图，加载未完成时明确覆盖范围。没有任意节点硬截断不等于浏览器内存无限，十万级图性能仍需独立验收。

## 验收

- 故障注入：明确断线可恢复；未知原因不猜测；目录或权限变化拒绝；正在读取的快照不重放；预算、取消及旧计时器边界保留。
- 日志：能看到安全驱动诊断、worker 退出和日志完整性；SQL、凭据及异常正文不泄漏；Windows 路径、读取和导出覆盖。
- 画布：超过 1,000/4,000 节点和跨批边不丢失；权限/版本切换不串图；暂停、继续和错误反馈可操作；节点仍为圆形。
- Agent：超时反馈保留草稿且允许不同的合理探查；skill 的成本说明不等于两亿行性能或真实自主发现验收。
