# 上下文、复核协议和图谱展示修正

> 设计状态（2026-11-03）：本页保留原版本的方案、故障与验证记录。当前通用构图目标、Harness 迁移与 YAML 产物规范见 [按用户目标自主构图](GENERIC_GRAPH_CONSTRUCTION.md)。本文的历史通过结果不证明新路径已验收；未被迁移改变的接入、执行、权限及平台约束继续适用。

本轮先区分两份证据。当前工作区的五表实验完成了 462 个业务节点、1650 条边，状态仍为 PARTIAL；真实数据两次运行只有用户提供的汇总，不能据此宣称已经复现或确认具体超时根因。

## 诊断与修改方向

1. 输入窗口、HTTP 字节上限、累计 token 预算分开。现有 UTF-8 字节数不能当成 token 数；“四个字符一个 token”也不能用于所有中文、编码和 JSON。优先使用供应商 usage，缺失时明确标记估算。上下文先裁减完整工具交换，保留任务、字段模型、已提交结果和纠错信息；只有材料仍超限才结束探索。
2. 原始查询行只留在任务内存。保留稳定字段认识、授权引用和安全统计，在每次请求动态组装。参考 DeepSeek Harness 将持久事件和模型可见上下文分离的做法，但本项目不引入源数据落盘。传输超时、JSON 协议错误和业务反驳分别计数；一次返回可能产生多个字段诊断，不能把诊断条数当作复核调用数。
3. 模型使用任务内短引用，内部和产物继续使用原始 ID。仅转换已经签发的引用字段，不改 SQL、业务编码、名称、原始值或自由文本。未知引用仍由原有校验拒绝，不做模糊匹配。独立语义复核与探索工具采用相同的映射原则。
4. 对象在多个层位出现、具有多个父路径，本身不是身份冲突。是否共用一个对象仍取决于编码域和作用域；同码异名需要判断别名、多值属性或身份冲突，不能靠“多位置”自动消解。业务反驳应留下可执行的修订项；PARTIAL 必须说明尚未覆盖的目标或未处理的错误，不能仅因曾经出现过一次拒绝而成立。
5. 图谱以节点名称、关系中文说明和结构化属性为主。技术 ID 和原始 JSON 放在展开区，作为追踪入口。未知关系保留原始名称，不能编造中文含义。

## 验证边界

用固定回归验证中文/英文 token 估算、完整工具交换裁剪、短引用往返与隔离、半截参数不执行、多位置身份规则、拒绝反馈及 UI 端点名称。再运行后端测试、前端测试和构建。真实数据不在本机，本轮不调用真实模型，不用本地测试结果代替真实数据抽取验收。

## 本轮落实与结果

- 最新本地实验 `full-extraction-v2-recovery-status-20261102T061219Z` 的层级已经发布；PARTIAL 来自 6 次未完成提交、4 项延后工作，以及剩余关系与属性覆盖任务。本轮没有模型传输失败或响应截断。18 次草稿拒绝分为 12 次工具参数错误、3 次证据引用错误、3 次拒绝记录解决方式错误，不能解释成层级身份被整体驳回。
- 462 个业务节点、1650 条边中，有 720 对端点各被两种不同名称的关系连接。已发布关系映射此前未进入下一轮关系任务，现已补齐映射和词表。保留旧产物，不按端点相同自动删边。
- 状态判断与任务调度都忽略已经恢复、仅用于诊断的历史错误；真正尚未完成的工作仍标 PARTIAL。字段模型替换失败会指出具体缺失角色、层位和所需列；匿名关系草案也有明确重提、撤回步骤。
- 短引用在探索工具与独立复核中生效，包含列、文档章节、对象、规则、候选和主张引用。映射会预留已存在的短 ID，拒绝碰撞；不改业务词表的枚举值，不改查询参数和行值，不以短引用授予新权限。
- 图谱默认展示中文定义、端点名称和属性表，技术结构可展开。已恢复 API 的安全字段诊断投影，并从原始报告重新投影工作台的结果副本，原实验及其哈希保持不变。
