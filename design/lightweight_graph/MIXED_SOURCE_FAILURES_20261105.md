# 混合来源故障、修订损失与结构预览

日期：2026-11-05。客户运行仅有用户转述的轨迹，未接触真实数据库、草稿和图谱。本文区分反馈中的现象、代码可复现问题和仍需现场证据的原因。

## 可以确认与不能确认的结论

`read_only_transaction_failed` 表示建立只读事务的操作失败。它本身不能区分网络断连、空闲连接失效、权限、配置、事务中止或超时；不能据此宣布只是把 60 秒改成 120 秒便会恢复，也不能认定永久禁止读取。

当前代码按实体类型和完整键识别节点。同一键出现在多个层位合法；不同键同名合法。`same_identity_conflicting_label` 指同一身份、同一可见范围有两个非空主名称。把名字降为别名、展示组件，或者用筛选丢弃冲突行，都不构成解决冲突的证据。不同实体类型的相同编码不是自环，不应因此把关系 `equal_endpoints` 改为 `omit`。

`GROUP BY ... LIMIT` 和 `DISTINCT ... LIMIT` 限制返回量，不保证限制扫描量。完整实例验证仍检查目标范围内的必要投影，不能用有限样本冒充完整验证。客户材料中节点分类数量也没有完全相加到总数，不据此宣布已经完成全图对账。

## 已复现的实现问题与修改方向

1. **开事务失败缺少清理。** Gauss/MySQL 的事务开始发生在原 finally 之前，失败可能不回滚。现在失败开始也清理；原错误不会被清理异常覆盖。只对 Gauss 明确的 `25P02` 在尚未读取事实时尝试一次回滚重建，并重新验证只读与隔离级别。断线不自动重放查询或绕过接入预检。
2. **诊断被抹掉。** 探查入口的错误允许列表不包含部分事务/能力错误，最终变成 `tool_execution_failed`。新增经过白名单处理的来源、阶段、SQLSTATE/errno、类别、回滚结果及恢复建议，不保留驱动原文、连接串或密码。未知原因仍记 unknown；不可自动重试不等于永久禁止。
3. **先开全部来源导致整体短路。** 一个来源无法开快照时，原流程尚未执行任何映射就结束。现在记录失败来源，继续独立来源的候选计算；涉及失败来源及其端点依赖的映射明确记为受阻。整份草稿仍未通过，不把局部节点冒充完整发布。
4. **累计缓存挤占图谱预算。** 原实现保留每份一次性投影直到整轮结束。改为最后一个使用者完成后释放；查找索引仍引用的投影保持计费和存活。显示派生使用原图，最终派生字段也计入序列化大小限制。没有删除名称、属性或路径证据，也不将此限制称为 Python RSS 的精确上限。
5. **名称检查只看定义，不看节点覆盖。** 一个映射有主名称会使整类对象免于提示，即使深层独有节点只有别名。新增可见实例的覆盖诊断；空字符串主名称统一按缺名处理，两个不同的非空名称仍冲突。不会凭列名、语言或别名列表自动决定正确主名称。
6. **修订删减缺少反馈。** 保存新修订时比较删除的来源、对象、关系、物理映射、主名称角色和上下文列，返回非阻断建议。原修订仍在；执行失败不能作为删减用户要求的依据。用户主动缩小范围仍允许，不把所有删改自动判断成目标缺口。
7. **结构检查成功却无法查看旧方案。** 结构检查产物已经保存完整定义及绑定，实例为空不妨碍查看类型图。新增独立结构预览：读取经过摘要和当前权限校验的历史结构记录，选择草稿和修订，展示实体类型、关系定义及字段绑定；不查事实、不改变发布头、不伪造实例节点。历史或未发布状态明确显示。

## 保留的边界与后续能力

独立来源先算不等于失败依赖可以忽略。合法拆分应建立独立草稿、分别验证发布，并保留原目标的未完成部分。不能静默将包含数据库的原目标替换为仅 Excel 的目标。

图中每份路径支持仍保留行上下文，重复信息可能真实超过预算。缓存释放解决的是临时重复，不能保证所有图在 32 MiB 内完成。大图需要明确资源配置或分组方案；长期可将上下文规范化为权限受控的共享记录，但不能未经格式迁移直接删除支持中的信息。

`ytd/mtd/lyytd` 等列不天然等同于独立 Measure 对象，是否作为概念应由目标及文档确定。本次故障修复时只有行映射，身份来自行值；把数值列全塞进 properties 会扩大实例投影，不能生成度量定义。后续已新增有证据约束的 `metadata_column` 及行到列定义端点，见[列定义对象与关系](METADATA_OBJECTS_AND_RELATIONS_20261105.md)。这项能力需要 Agent 显式映射，不按列名自动生成。

本轮工程验收覆盖故障注入、健康来源候选保留、名称覆盖、缓存与证据不丢失、修订提示和历史结构预览。真实 Gauss 故障原因、两亿行性能及自主发现质量仍需客户运行证据，不由单元测试或候选规模替代。
