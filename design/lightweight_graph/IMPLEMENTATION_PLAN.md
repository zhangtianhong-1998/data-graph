# 轻量图谱：实施、迁移与验收计划

版本：1.0（2026-10-17）。本文保留实施规划；当前完成情况及未验证范围见 [实施与验收记录](../../IMPLEMENTATION_STATUS.md)。计划中的阶段目标不自动等于验收通过。

阅读顺序：[README](README.md) → [US](US.md) → [SDD](SDD.md) → [发现工作流](DISCOVERY_WORKFLOW.md) → 本文。SDD 是数据契约与关系注册表的唯一规范来源；本文定义实施依赖、责任与验收。

## 1. 实施方式

以仓库根目录为交付目录，独立运行包放在 `src/lightgraph/`。此前的 ontology route2 与 xiaomeng 项目作为设计参考，不串联旧 pipeline，不迁移其源数据存储。2026-10-18 已完成代码实现和合成实验，真实数据库与模型接入另行验收。

三条执行要求：

1. 先定义 SourceAdapter、Store 白名单、规则与支持契约、预算和失败语义，再迁移算子，避免带入本地全量落盘、DuckDB 专用语法和物理行号身份。
2. 每阶段交付正常样例、反例和真值对照；“能跑”“有图”“节点减少”均不能代替正确性。
3. 旧项目先在隔离副本跑离线基线，再逐项迁移。检查测试入口不调用付费模型或真实数据，记录通过、失败和未运行；不影响旧工程的运行中实验。

首期范围：一个实际验证过的 Gauss 产品/版本、Excel、Markdown、实体列组、宽/长层级、受限跨表引用、共享实体、两类文档、源端 DISTINCT 对账、元数据图与业务图浏览、导出。不主动创建 CDC/复制槽，不做源库写回，不将每条观测值实例化。

### W0：契约、真值与骨架（4～5 人日）

交付：

1. 独立包、配置、离线测试与 CI 骨架。
2. StructuredSource、KnowledgeDocument、ExtractionGoal、DataUnderstanding、Hypothesis、RuleSpec、GraphFact、GraphNode/Edge、Support、DocumentClaim、ValidationRecord、RunManifest 的严格 schema。
3. Store/PersistencePolicy/EphemeralBatch 与保留矩阵；只允许通过输出契约的目标图事实、受控候选及无原值控制信息落盘；候选不进入 accepted 视图，不允许自由 evidence 或任意 JSON 绕过。
4. 关系注册表、属性级支持、稳定身份与隔离域。事实 ID 不含来源、租户、规则版本；支持记录包含这些范围；每份发布不可变地记录验证版本、文档修订、binding_revision 和状态，避免重验覆盖历史出处。跨客户隔离域不自动共享。
5. F01～F15 真值与装置。首条纵切用 8～12 张表、合计约 3,000～10,000 行、3～6 份 Markdown；完整场景用变体/故障注入覆盖，真值由评测器隔离持有。
6. 旧工程版本、工作区指纹、隔离副本离线测试基线与迁移清单。

退出条件：每个夹具有实体/属性/边/支持/禁止边或明确未决；契约能加载并拒绝非法字段。当前设计中的文件名不算夹具已经完成。

### W1：安全接入与不落盘（8～10 人日）

交付：

1. Gauss 能力预检与适配器：完整授权元数据、只读事务、参数绑定、游标/分页、超时/取消；同时提供测试替身。
2. Excel：原文件按上传策略管理，解析只在有界内存；保留前导零与空值，不执行宏、不重算公式、不访问外部引用，缓存值缺失显式报告。
3. Markdown：标题、表格、代码块、段落与版本定位；用途分类骨架，内容不改变工具权限。
4. 注册算子 → 参数化模板 → 严格单查询 AST → 对象/列/函数白名单 → 只读事务 → 资源限制。历史容错 SQL 解析器不承担安全执行检查，事务控制只由适配器发起。
5. Store 白名单与 `lightgraph retain-check`：输出、临时文件、日志、异常、SDK、流式接收端、模型网关、APM、spill、交换与崩溃转储。日志只收无值状态/计数/模板信息，不收参数 hash 或逐行 hash。
6. 最小导出、manifest 与可取消的预算记账。

验证：F09 拒绝集执行前拦截；F10 成功、失败、取消、重试、崩溃、流式输出六类路径 canary 零落盘。canary 放在目标排除的源属性，另测允许的图属性可发布；不能把全部保存禁止误当数据边界实现。原始统计返回体、DISTINCT 列表、prompt/响应同样不得缓存。

退出条件：目标 Gauss 产品/版本的隔离环境或客户测试库通过安全契约，记录驱动与版本。环境未到位仅可报告替身测试完成、Gauss 集成待验证；继续离线开发但不能通过 G2 或接真实样本。

### W2：数据认知与列组（7～9 人日）

交付：

1. 画像、格式计数、空值与 FD 算子；SQL 在源端聚合，只保存白名单批准的无原值验证结论，查询结果在内存销毁。
2. 目标 → 表用途候选 → 关键列/角色 → 联合投影草案，列出排除原因。重复事实不因编码不唯一而被拒；实体与关系分别按真实联合元组去重。
3. T1 表内、T3 层级、T5 反例修订契约与 mock/回放；此时只验证编排与失败恢复，不报告自动发现质量。
4. 数据说明检索、上下文包与 DataUnderstanding：声明、观察、推断、冲突分层，自动说明不作为独立第二份证据。

验证与退出：F01/F03/F13 的确定性算子与固定规则部分通过；销售费用四列组装正确，排序列不建节点；只有单组 l2 时不生成层级；同码异义、误导注释、前导零、空值可报告。自动发现效果待 D。

### W3：宽层级、固定规则与支持账本（8～10 人日）

交付：

1. 层级六阶段、宽转长、身份核对、缺层切段、段内重复压缩、邻接边与冲突；`A→NULL→C` 不默认生成 `A→C`。
2. RuleSpec 编译/解释器、流式联合投影、图事实组装与稳定 ID；不执行模型生成的任意代码或 SQL。
3. 支持账本与发布：节点存在、属性值、边、文档主张分别有支持。暂存只存合格图事实；`canary_check` 不提交发布；图事实、支持与逻辑水位原子提交。
4. 分区 generation CAS：head 按逻辑规则与分区定位，revision 不进入 head key。失效 worker 不能覆盖新代；截断、不一致或未完成分区禁止缺失撤回。
5. E 的结构部分：固定 RuleSpec 跑销售费用列组、宽层级、A/B 共享实体。第一次发布共享节点即测撤回 A 独有别名，B 节点与属性保留；不同规则对同一事实只增加支持。
6. 发现调度器骨架与三池预算。每个假设启动前预留最低核验成本，完成/失败结算实际成本并释放余量；不足则延期。40%/55% 仅为试点初值。

验证与退出：F02/F04 与 F07 最小撤回通过；`3/1/1/1/1` 压缩为 `3→1`，2711/2713 保持兄弟，缺层/多父/环/编码冲突分开报告。E 的结构部分通过不表示文档、自动发现或完整增量完成。

### W4：两类文档、自动发现与跨表关系（8～10 人日）

交付按以下顺序：

1. 固定文档结果/mock 接通数据说明与分析知识两通道，验证上下文选择、主张模态/条件/出处、文档支持撤回与无落盘，完成 E。mock 不证明文档理解正确。
2. E 通过后接 T1～T5 实际模型调用，独立验证 D；T2 处理引用、角色对齐、判别列分区，T4 处理文档，T5 仅在反例/前提失效时修订。
3. 跨表算子：覆盖率、唯一定位、条件内分母、缺目标、多义与受限 JOIN。SQL 结构核验不能替代语义证据。
4. 规则版本、依赖失效、审计、身份迁移与回滚：回滚后对当前来源重验重算，历史发布仅作历史视图，不恢复历史源单元格。
5. 元数据图接口：表→列、列组、独立语义边、双表字段对照。technical_link 的技术状态与语义状态分开，不改成业务确认。

验证与退出：D 只读取授权元数据、有界样本/统计、目标与说明文档，不预载人工列映射、参考规则或 Gold。评测器核对留出真值中的规则、实体、属性与边，单列误发现、漏发现、正确未决和成本；分析文档另核对条件/模态/绑定。F01/F02/F05/F06 的 E/D 报告独立。D 不达标须修订对应任务或算子，不以 mock 通过、节点减少或预算耗尽收口。

### W5：完整增量、恢复与导出（6～8 人日）

交付：

1. 三档增量：只消费已有且授权的 CDC；有更新时间无删除信号时明确删除不保证；无变更标记时源端投影重扫。禁止主动建复制槽或修改源库。
2. 完整一致分区对账：节点、属性/别名、边、主张分别撤回。失败、截断、权限变化、跨页不一致不删除旧支持。
3. 图事实、支持与无源值逻辑水位原子提交。业务 keyset 值只在内存，崩溃重读未完成分区；不持久化原始组合清单或逐行指纹。
4. 依赖未变且新增数据符合规则时 LLM 为 0。未知判别值、同码异义、新口径或前提失效只定向复核。
5. 权限过滤后的 JSON/YAML/CSV 导出、稳定排序与校验和；搜索、计数、label 与别名同样按有效支持裁剪。
6. 成本、覆盖、冲突、未决与恢复报告；千万行演练计划单列为扩大试点前条件，不作为首版功能验收前置。

验证与退出：F07/F08/F15 通过；固定真值下全量重建与增量维护的实体/属性/边/支持一致，运行统计与审计历史单独比较；规则回滚基于当前来源；无缓存恢复幂等。报告解释扫描仍发生、删除不可证明与一致性缺口。

### W6：展示、验收与试点（5～7 人日）

交付：元数据图展开列与双表对照；业务图实体/关系/来源/支持；冲突与覆盖视图；F01～F15 回归（启用 BI 加 F16）；E/D 独立报告；实际 Gauss 产品/版本/驱动集成报告；安装、配置、恢复、保留自检与迁移说明。

退出条件：全部 P0 满足 US §8。客户环境的结构/工具结果与业务语义质量单列；无客户 Gold 时不得把合成集 D 通过表述为真实业务语义通过。千万行成本演练在扩大试点前安排。

## 6. 测试与验收矩阵

| 方面 | 对照方法 | 必须保留的失败结果 |
| --- | --- | --- |
| 自动发现 | E 固定规则与 D 隐藏真值分开；D 用实际模型 | mock 不证明发现质量；人工映射不得进入 D 输入 |
| schema | 正确/回声/误导注释 | 无说明不硬猜；声明与观察冲突保留 |
| 文档 | 无文档/正确说明/过时说明/分析文档 | 模态、条件与出处不丢失，说明不自证 |
| 重复事实 | 固定语义真值，重复行放大 | 图集合稳定；扫描成本可能上升 |
| 联合投影 | 真实联合元组对照 | 不产生逐列 DISTINCT 笛卡尔伪配对 |
| 身份共享 | 同义不同编号/同名不同公式/不同规则同事实 | 事实共享、支持可分别撤回；缺定义不跨接冲突 |
| 层级 | 单 l2、宽/长、填充、缺层、环、多父、编码冲突 | 无自环、无默认跨空层边、同父 L5 不变父子 |
| 增量 | 全量重建与增量维护比较 | 实体、属性、边、支持一致；不完整分区不撤回 |
| 原子性 | query/transform/check/publish/cursor 注入失败 | canary_check 不发布；head CAS 防旧 worker 覆盖 |
| 权限 | A/B 共享实体的访问/搜索/计数/导出 | 私有 alias、label、支持不可泄露 |
| 保留 | 成功/失败/取消/重试/崩溃/流式六路径 | 无源行、原始投影、参数 hash、完整请求响应落盘 |
| 方言 | 实际产品/版本/驱动契约 | DuckDB/PostgreSQL/替身不替代 Gauss |
| 成本 | DB、LLM、时间/内存分池 | 预留不足延期，超限取消与覆盖状态可核对 |

每个 F 样例都记录预期未决。所有目标范围对象与假设有处理状态；已验证、未决、延期比例分开，延期不是成功。增加百万/千万行只评估扫描与组合增长成本，不能用规模压缩率替代语义正确性。

## 7. 风险登记

| 编号 | 风险 | 触发信号 | 处理与责任 |
| --- | --- | --- | --- |
| R1 | Gauss 能力与假设不符 | 预检失败或 SQL 不支持 | 接入负责人限定版本、补适配；不放宽安全检查 |
| R2 | 日志/网关/部署破坏无落盘 | canary 命中或配置不符 | 安全负责人阻断真实样本、修复并重验六路径 |
| R3 | 自动发现不足 | D 错误规则/漏发现/延期多 | 发现负责人改任务/算子/预算，不重复重试掩盖缺能力 |
| R4 | 业务口径无法确认 | 同码异义、映射冲突 | 业务负责人提供说明或保持未决，不能猜编码映射 |
| R5 | DISTINCT 成本过高 | 超时、扫描预算触顶 | 接入负责人按分区/窗口执行，缩小覆盖并报告 |
| R6 | 删除或并发发布错误 | 不完整读取后支持减少、旧 worker 覆盖 | 增量负责人修复完成标记与 CAS，完整一致分区才撤回 |
| R7 | 迁移耦合旧存储 | 算子依赖 Dataset/行号/源快照 | 迁移负责人拆纯算子，重写接口，不搬旧 pipeline |
| R8 | 无客户语义 Gold | 只有工程测试 | 验收负责人分开结构、发现与真实语义结论 |
| R9 | 展示误导 | 技术边被当业务确认 | 前端/数据负责人按注册表展示状态和证据 |
| R10 | 文档冲突或恶意指令 | 改权限/要求留存/过时含义 | 文档负责人保持用途与来源边界，工具策略不可覆盖 |

触发风险后更新对应 US、测试与台账；不以“整体成功”隐藏未覆盖。

## 11. 完成定义（DoD）

每个任务必须有输入/输出和失败态契约、正常/反例/越权/超限测试、无落盘检查、预算与覆盖记录、对应 US/SDD 更新。涉及发现质量须报告 D 的模型版本、输入范围、真值隔离、错误与未决，不可引用 E/mock 代替。

每阶段须满足退出条件与全部适用夹具。客户数据语义没有 Gold 时明确未验收；测试通过、退出码、图规模均不能扩大结论。

## 12. 台账与变更规则

每条 US/F 场景维护 `not_implemented/not_run/passed/failed`，关联负责人、提交版本、E/D/I 门、命令、报告和未覆盖项。当前设计阶段统一为 `not_implemented`；文中命令不是执行记录。

契约变更先改 SDD 唯一来源，再同步工作流、US 与本计划。身份、权限、支持撤回、保留白名单或 SQL 权限变化，必须补反例与迁移语义。模块名称可调整，责任和验收不能丢失。

46～59 人日仅为粗估。W1/W2 后依据真实接入与算子成本重估；预算不足时缩小覆盖范围并记录缺口，不降低只读、无落盘、身份和撤回约束。
