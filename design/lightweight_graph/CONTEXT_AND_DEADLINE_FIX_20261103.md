# 查询时限、工作上下文与表格输入整改

> 设计状态（2026-11-03）：本页保留原版本的方案、故障与验证记录。当前通用构图目标、Harness 迁移与 YAML 产物规范见 [按用户目标自主构图](GENERIC_GRAPH_CONSTRUCTION.md)。本文的历史通过结果不证明新路径已验收；未被迁移改变的接入、执行、权限及平台约束继续适用。

本轮根据空白库实验零规则的轨迹，修复查询预算泄漏，同时减少 Agent 每轮重复读取的数据。这里只记录代码行为和离线验证；没有重跑真实模型，也没有修改已冻结实验或清理既有轨迹。

## 零产出的程序问题

数据源共用一个 `QueryBudget`。旧工具实现执行查询前，用当前表的截止时间永久缩短这个共享预算。工作流进入下一张表时只恢复模型预算，查询预算仍停在上一张表的截止时间。于是首表超时后，下一张表可能在首次 SQL 查询时直接报 `run_time_budget_exhausted`，工作流将其误认为整个运行结束。

现在查询只在执行期间借用较短时限，在成功、异常或迭代器提前关闭时恢复外层时限。跨源查询按预算实例去重；单表超时报 `wall_time_budget_exhausted`，真正耗尽探索阶段或整个运行时保留相应分类。已经消耗的查询数、返回行数、字节数不会重置。

回归测试使用真实内存数据源及两表发现流程：第一张表在推理或 SQL 阶段超时后，第二张表仍能查询、验证并产出规则。这修复了提前中断后续表的 bug，不代表第一张表的语义问题已解决，也不保证真实模型必然产出规则。

## 表格只传一次表头

模型输入采用 JSON 中的有序表头与二维行数组：

```json
{
  "columns": ["指标编码", "中文名", "英文名"],
  "row_format": "positional_values",
  "rows": [["M01", "应收账款占用", "Accounts receivable"], ["M02", "销售成本", "Cost of sales"]],
  "complete": false
}
```

初始样本的表头同时带列 ID、名称和已知类型；SQL 输出保持查询返回的列顺序。重复列名按位置区分，不覆盖单元格。字符串编码、数值、布尔值、转义字符和实际 `null` 保持类型。被过滤或未提供的单元格通过 `omitted_cells` 明确标记，不能当作实际空值。样本、截断和完整性标记不变。工具执行协议与规则验证仍使用原来的内部结构。

固定测试样例为 15 列、100 行，包含中文、逗号、引号和换行：旧逐行对象输入 66,108 字节、估算 32,892 tokens；共享表头输入 30,141 字节、估算 16,407 tokens。这里比较的是同一数据的请求表示，估算值不是服务商实测用量；不能推断所有表都有相同降幅。

## 不等硬窗口耗尽才压缩

新增 `working_context_tokens`，默认 32,768，可在前端保存，留空即关闭。它是请求工作集的软目标，不是累计 token 预算，也不改变用户配置的 1,048,576 输入和 65,536 输出上限。独立 Agent 配置和内联配置均支持保存，下次启动使用新修订；正在运行的实验继续使用启动时配置。

每次发现请求先处理旧的完整 source 工具回合。优先将其结果投影为已有证据引用、列头、计数和完整性信息，必要时再移除整个旧回合。系统约束、当前结构知识、提案、校验反馈、最近完整 source 回合保留；调用与响应不拆散。摘要不含原始行、不生成业务判断，也不将候选变成确认事实。需要被省略的细节时，Agent 仍须在剩余额度内查询授权来源。

不可压缩材料超过软目标时记录 `target_unmet`，继续执行正常硬上限检查，不凭软目标直接失败。每次压缩记录前后估算 tokens、字节数、压缩结果数和省略回合数。请求使用副本；原始工具轨迹、实验产物和证据注册不因压缩删除。

本轮不增加辅助摘要模型调用，不读取任意缓存文件，不引入新的 Agent 内核。采用机制及 Hermes 替换成本见 [Hermes 本地源码评估](HERMES_CONTEXT_REVIEW_20261103.md)。

## 验证范围

测试覆盖两表超时恢复、跨源共享预算、迭代器退出、短 ID 与单元格值隔离、稀疏/重复列、工具调用配对、字段校验反馈保留，以及实际 AgentScope 请求压缩后成功提交、原始轨迹仍可导出。前端测试覆盖软目标保存、刷新恢复、关闭和硬窗口独立性；本地 HTTP 模型桩验证保存配置确实传给新 worker。

2026-11-03 验证记录：后端全套 2,588 项通过（152.23 秒），前端 234 项通过，前端类型检查和生产构建通过。后端日志为 `/tmp/ict-context-deadline-final-backend-20261103.log`，前端测试与构建日志分别为 `/tmp/ict-context-deadline-full-frontend-20261103.log`、`/tmp/ict-context-deadline-build-20261103.log`。这些均为本地工程验证，不含外部模型实验。

随后补充“摘要必须减少估算 tokens，字符变短并不足够”的收益检查，压缩算法与 AgentScope 请求集成共 18 项回归再次通过（21.32 秒），日志为 `/tmp/ict-compaction-final-regressions-20261103.log`。

真实网关的理解准确率、单次推理耗时、全量抽取产出及最终状态尚未验证。软目标是可调整的起点；固定提示、当前证据或保留反馈仍可能超过它。独立语义审查继续读取完整绑定证据，本轮没有用摘要替换审查依据。扩大超时或更换内核，也不能代替这些验收。
